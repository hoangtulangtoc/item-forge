# Sample textures

These PNG files are used by the sample items, armor, and block definitions. Copy them into the
plugin's texture folder on your Paper server:

```bash
cp -r examples/textures/. /path/to/server/plugins/item-forge/textures/
```

Then run `/item-forge reload` or restart the server to rebuild the resource pack. Item and block
textures use their configured ids. Armor uses an icon texture and separate body or leggings
textures.
